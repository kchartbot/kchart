# 차트봇

가이섬.com 의 멜론·지니·플로·벅스 차트를 가져와서, 새 디자인의 이미지와 텍스트로 만들어 디시 갤러리에 올리는 봇입니다.

```
가이섬 수집 (fetch.py) → 디자인 렌더 (render.py) → 디시 업로드 (dcinside.py) → 주기 실행 (run.py)
```

## 지원 차트

| 키 | 차트 | 형태 | 주기 |
|---|---|---|---|
| `melon_top100` | 멜론 TOP100 | 표 (이용자 수치 포함*) | 시간당 1회 |
| `melon_hot100_five` | 멜론 HOT100 5분 차트 | 그래프 | 5분 |
| `melon_hot100_graph` | 멜론 HOT100 그래프 | 그래프 (최근 24시간) | 시간당 1회 |
| `melon_five` | 멜론 5분 차트 | 그래프 | 5분 |
| `melon_realtime` | 멜론 실시간 차트 | 단순 표 | 시간당 1회 |
| `melon_24h_count` | 멜론 24시간 이용자 수 | 곡별 24시간 표 3열 (시간·순위·T100·이용자수·증감) | 시간당 1회 |
| `genie_realtime` | 지니 실시간 차트 | 단순 표 | 시간당 1회 |
| `flo_chart` | 플로 차트 | 단순 표 | 시간당 1회 |
| `bugs_realtime` | 벅스 실시간 차트 | 단순 표 | 시간당 1회 |

지니·플로·벅스는 가이섬에 있는 항목 중 위 형태에 해당하는 것만 넣었습니다. 플로는 "FLO 차트"(24시간) 하나뿐이라 실시간 차트에 가장 가까운 단순 표로 만들었습니다.
지니·벅스의 일간 차트, 지니 실시간 그래프도 가이섬에 있지만 요청하신 목록에 없어서 뺐습니다 (`chartbot/fetch.py` 의 `SPECS` 에 한 줄 추가하면 됩니다).

\* 가이섬의 TOP100 이용자 수치(1시간/24시간)는 **현재 모든 곡이 비어 있습니다** (여러 시각을 확인). 값이 들어오면 자동으로 수치 열이 나타나고, 비어 있으면 순위만 표시하며 이미지 아래에 안내 문구가 붙습니다. 이용자 수가 실제로 오는 건 "24시간 이용자 수" 차트의 3곡뿐입니다.

## 설치

```bash
pip install -r requirements.txt
playwright install chromium
cp config.example.toml config.toml   # 열어서 gallery_id 와 올릴 차트 선택
```
Python 3.11 이상이 필요합니다.

## 사용 순서

1. `python run.py render` — 샘플 데이터(운영과 같은 코드 경로)로 `out/` 에 9종 이미지 생성. 디자인 확인용 (네트워크/로그인 불필요). 한 종류만: `--only melon_top100`
2. `python run.py once` — 가이섬에서 실제 데이터를 가져와 렌더. `dry_run = true` 라 업로드는 안 합니다.
3. `python run.py login` — 열린 창에서 **직접** 디시 로그인 후 창 닫기 (1회). 비밀번호/캡차는 코드가 다루지 않습니다.
4. `python run.py once --headed` — 창을 보면서 업로드 1회 테스트. `config.toml` 에서 `dry_run = false` 로 바꾸고 실행하세요. 처음엔 선택자(`[dc.selectors]`)를 맞춰야 할 수 있습니다. 실패하면 `out/dc_error.png` 에 화면이 저장됩니다.
5. `python run.py loop` — 상시 실행. 서버라면 systemd/pm2, 윈도우라면 작업 스케줄러에 등록하세요.

## 동작 방식

- 5분마다(정각 + 20초) 깨어나서, 5분 차트 2종은 매번 새 칸이 있는지 확인하고, 나머지 7종은 **매시 5분 이후 시간당 1회**만 올립니다 (`hourly_after_minute`). 이미 올린 시간대는 요청 자체를 하지 않습니다.
- 시각은 서버 시계와 무관하게 한국시간(KST)으로 계산합니다.
- 새 시간대 페이지가 아직 비어 있으면 직전 시간대를 쓰고, 이미 올린 것이면 건너뜁니다.
- 게시글 제목은 `[11:30] 멜론 5분 차트` 형식, 본문은 이미지 + 곡별 텍스트 + 출처입니다.
- 곡이 많은 차트는 상위 100곡까지만 표시합니다 (지니는 사이트에 250곡). 100곡 표는 2단(1~50 / 51~100)으로 나옵니다.

## 꼭 알아둘 것

- **업로더(`dcinside.py`)는 실제 로그인 상태에서 검증하지 못했습니다.** 디시 글쓰기 화면의 선택자는 추측값이고, 4번 단계에서 맞춰야 합니다. 수집·렌더·주기 실행은 실제 가이섬 데이터 구조로 검증했습니다.
- **출처 표기**: 가이섬 이용약관 6조 2항에 따라 이미지와 본문에 `출처: 가이섬.com` 이 항상 들어갑니다. 지우지 마세요. 가능하면 운영자(guysomedc@gmail.com)에게 자동 수집·게시 허락을 구하세요.
- **요청량**: 차트 1개당 페이지 1개(시간당 차트는 시간당 1~2회), 요청 사이 3초 이상 간격. 앨범 이미지는 한 번만 받아 캐시하고 한 번에 30장까지만 새로 받습니다(처음엔 몇 주기에 걸쳐 채워지고, 못 받은 곡은 첫 글자 타일로 표시됩니다).
- 9종을 모두 올리면 한 시간에 글이 31개(5분 차트 2종 × 12 + 나머지 7종) 올라갑니다. 디시의 도배/자동 글쓰기 제한과 갤러리 운영원칙에 걸리지 않는지 확인하고, 필요하면 `charts` 에서 줄이세요. 캡차가 뜨면 자동 업로드가 멈춥니다(우회하지 않습니다).
- **24시간 이용자 수**: 곡 상세 페이지(곡당 1회)와 24시간 전 시간대 페이지 3개(한 번 받으면 `out/cache/hist` 에 저장)를 추가로 읽습니다. 순위는 실시간 차트 순위, T100은 TOP100 순위, 새벽(2~7시)에 실시간 순위가 비면 직전 순위를 이어 씁니다. 표 색은 한국식(상승 빨강/하락 파랑)입니다.
- 원본 봇의 "1~3위 예측" 값은 산출 방식을 알 수 없어 넣지 않았습니다.

## GitHub Actions 로 돌리기

저장소에 이 폴더 내용을 그대로 올리면 `.github/workflows/chartbot.yml` 이 5분마다 `python run.py once` 를 실행합니다 (시간당 차트는 매시 5분 이후 1회만 올라감).

1. **저장소 만들기**: 비공개(Private) 권장. 로그인 정보는 Secrets 에만 들어가지만, 비공개가 안전하고 실패 화면 보관도 됩니다. 단, 비공개는 무료 시간이 월 2,000분이라 5분마다 돌리면 부족할 수 있습니다 (한 번 실행에 1~2분 걸림). 공개(Public)는 무제한이지만 코드가 공개됩니다.
2. **로그인 상태 만들기** (내 PC에서 1회): `python run.py login` → 열린 창에서 직접 로그인 → 창 닫기 → `python run.py export-session` → 생긴 `dc_session.json` 내용 전체를 복사.
3. **Settings → Secrets and variables → Actions**
   - Secrets: `DC_STORAGE_STATE` = 위 JSON 전체. (붙여넣은 뒤 `dc_session.json` 은 지우세요. 비밀번호와 같은 값입니다.)
   - Variables: `DC_GALLERY_ID` = 갤러리 ID, `DC_MINOR` = `true`/`false`, `DRY_RUN` = `true` (처음엔 true 로 두고 Actions 탭에서 이미지가 정상 생성되는지 확인 → 이후 `false`).
4. **Actions 탭 → chartbot → Run workflow** 로 수동 1회 실행해서 확인.

알아둘 점
- 스케줄은 정확하지 않습니다. 5분 차트는 실행이 밀리면 칸이 건너뛰어질 수 있습니다 (글 제목은 실제 최신 칸 시각으로 붙습니다). 정시성이 중요하면 PC/서버에서 `python run.py loop` 로 돌리세요.
- 로그인 쿠키는 만료됩니다. 업로드가 "로그인 세션이 없습니다" 로 실패하면 2번을 다시 해서 Secret 을 교체하세요.
- GitHub 서버(해외 IP)에서 접속하면 디시가 캡차를 띄우거나 막을 수 있습니다. 이 경우 업로드는 실패하고(우회하지 않음) 로그에 남습니다.
- 공개 저장소는 60일간 활동이 없으면 스케줄이 자동 중지됩니다.
- 업로더는 아직 실제 로그인 상태로 검증하지 못했습니다. 선택자 조정이 필요할 수 있습니다.

### 아이디/비밀번호로 직접 로그인 (쿠키 방식 대신)
Secrets 에 `DC_ID`(식별 코드), `DC_PW` 를 넣으면 세션이 없을 때 워크플로가 직접 로그인하고, 세션은 실행 사이에 캐시되어 재사용됩니다 (`DC_STORAGE_STATE` 는 필요 없음). 말머리가 없는 갤러리는 Variables 에 `DC_HEADTEXT` 를 빈 값으로 두세요. 캡차가 뜨면 실패합니다 (우회하지 않음).

## 가이섬 없이 직접 수집 (GitHub Actions 기본)
가이섬이 GitHub 서버 접속을 거부(429)해서, 기본 설정(`config.actions.toml`)은 멜론·지니·벅스 공개 차트 페이지에서 순위를 직접 가져옵니다 (`chartbot/direct.py`).
- 순위 표 3종(멜론/지니/벅스 `*_rank`) + 24시간 순위 추이 그래프 3종(`*_rank_graph`), 5분 순위 추이(`*_rank_five`)는 주석으로 꺼져 있음.
- **이용자 수·점수(HOT100 점수 등)는 없습니다** (가이섬 고유 값). 그래프는 점수가 아니라 **순위 변화**입니다.
- 순위는 5분마다 `out/rank/` 에 기록되어 그래프에 쓰이며, 기록이 쌓이기 전(처음 24시간)에는 그래프가 일부만 채워집니다.
- 각 사이트 이용약관을 확인하세요. 출처는 이미지와 본문에 `출처: 멜론 차트 (공개 순위)` 식으로 들어갑니다. 파서는 각 사이트 페이지 구조(HTML)에 의존하므로 개편되면 `direct.py` 를 고쳐야 합니다.
